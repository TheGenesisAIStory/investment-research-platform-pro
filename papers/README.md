# Papers

Cartella di lavoro per archiviare i paper/brief che vogliamo trasformare in esperimenti riproducibili.

Convenzione consigliata per ogni nuovo paper:

- `paper.md`: testo o sintesi strutturata del paper.
- `notebook.ipynb`: notebook Colab/eseguibile per testare l'idea.
- `README.md`: note operative, dataset attesi e stato dell'esperimento.

Paper aggiunti:

- `italian_banks_ml_stock_screening`: ML per fair value, mispricing e stock screening delle banche italiane quotate.
