# Laboratorio Research Library

Curated notebook reference library for `research_platform_definitive`.

This is intentionally selective. It keeps only old notebooks that can improve the canonical Research Platform: data platform, factor research, ML Stock Lab, portfolio/risk, valuation/smart-money data, financial text, and optional market microstructure.

## Files

- `LABORATORIO_MANIFEST.csv`: machine-readable curated inventory.
- `BEST_PRACTICE_REVIEW.md`: selection rationale and external best-practice mapping.
- `BEST_PRACTICE_REPOSITORIES.csv`: reviewed open-source repository patterns and platform actions.
- `COLAB_REVIEW_CHECKLIST.md`: promotion checklist before any reference notebook becomes a runnable platform workflow.
- `notebooks_ml4t_reference/`: curated notebook subset.

## Current scope

- Curated notebooks: **75**
- Total retained files: **129**

## Rule

Do not add raw notebook dumps here. Add a notebook only if it has a clear `promotion_target` and improves one canonical platform layer.
