# Analysis Studio Prompt Templates

Use these templates to request consistent professional workflows inside the local workspace.

## Stock Screening

```text
Run Analysis Studio stock screening for the {universe} universe, filtered to {sector}, and export the top {top_n} names with charts and executive summary.
```

## Portfolio Risk

```text
Analyze portfolio risk from {portfolio_file}. Show weights, annualized volatility, VaR, CVaR, risk contribution, and export the report.
```

## Earnings Analysis

```text
Run an earnings surprise and post-event drift study for {ticker}. Export the event table, surprise chart, drift chart, and analyst summary.
```

## Portfolio Builder

```text
Build a {risk_profile} model portfolio from {universe}. Include target weights, expected return proxies, risk diagnostics, and export files.
```

## Technical Analysis

```text
Run technical analysis for {ticker}. Include trend, RSI, MACD, price chart, momentum chart, and a concise trading interpretation.
```

## Competitive Analysis

```text
Run competitive analysis for the {sector} sector. Rank companies by growth, margin, innovation, valuation, and moat score.
```

## Quantitative Research

```text
Run single-name quant research for {ticker}. Build lag-safe factors, evaluate forward-return diagnostics, and export charts.
```

## Macro Analysis

```text
Run macro exposure analysis for {portfolio_file}. Estimate factor sensitivity, scenario PnL, and the largest macro risks.
```
